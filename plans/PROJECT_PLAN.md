# 项目规划与演进记录

> 本文档整合了项目从 v1 到 v5 的完整演进历程、当前状态、已完成的里程碑和下一步规划。
> 最新状态以本文档和根目录 `PLAN.md` 为准。

---

## 一、项目概述

**AI 全托管小店** — 面向"想开店但不会运营的个人卖家"的全栈电商平台。电商为骨架，AI 深度集成为灵魂。

- **后端**：FastAPI + SQLAlchemy 2.0（异步）+ Pydantic V2 + JWT + 事件总线
- **前端**：React 18 + TypeScript + Vite + Ant Design 5 + Zustand + Tailwind
- **数据库**：开发 SQLite / 生产 PostgreSQL（同一 ORM）
- **设计风格**：简约精选风（Apple / Shopify / Nordstrom）

## 二、里程碑演进

### v1 · 基础骨架（已完成 ✅）

三角色 RBAC（buyer / merchant / admin）+ 订单状态机 + AI 降级（无 key 走本地确定性 mock）+ 端到端冒烟。

### v2 · 功能拓展（已完成 ✅）

图片上传、搜索增强、积分/会员、优惠券、收藏、WebSocket 实时通知、个性化推荐、AI 营销/定价、多商家、报表、工单、退款、物流、审计看板、i18n。

### v3 · 内容扩展（已完成 ✅）

- **数据充实**：二级分类 17 个、商品 61+、评价含图/差评/1~5 星分布、4+ 商家、Banner/促销/优惠券全部补齐
- **首页重构**：轮播 Banner、多级分类、限时秒杀、排行榜、领券中心、店铺街、主题频道、猜你喜欢
- **商品详情**：评价含图/视频/追评、问答 Q&A、浏览历史
- **买家中心**：地址簿、积分成长、签到、消息、收藏

### v4 · 商业闭环（已完成 ✅）

- **内容社交**：商品问答 Q&A、关注流动态、评价增强
- **AI 深化**：实时行为序列推荐、AI 首页编排、客服知识库自学习、AI 选品/趋势洞察
- **营销增长**：分销裂变佣金、促销活动扩展（满赠/N 元任选/第二件半价）、直播带货
- **交易履约**：预售定金膨胀、电子发票、小额退款自动审核
- **商家平台**：子账号权限矩阵、AI 比价、经营报表+定时邮件、审计回放
- **买家体验**：个性化首页、通知分类免打扰、PWA

### v5 · 体验优化与安全加固（已完成 ✅）

#### 工程与性能优化

- 路由级代码分割（~40 路由 `React.lazy` + `Suspense`）
- N+1 审计（全量扫描 0 命中）、热点列索引与缓存
- 前端单测基建：Vitest + RTL，48 用例
- 安全响应头中间件（CSP / X-Frame-Options / HSTS）+ 请求体 10MB 上限
- 统一分页 meta 响应头 + 静态资源一年不可变缓存
- 分面检索、搜索联想、AutoComplete
- `docker-compose.yml`（Postgres + 后端一体栈）
- GitHub Actions CI（pytest / tsc / vitest / build / 依赖审计 / gitleaks）
- 图片管线（Pillow 压缩 + 前端懒加载）、结构化 JSON 日志

#### UI 美化（简约精选风）

- 设计系统：`theme.ts` 加大圆角（12/16）、柔和阴影、`--ease-soft` 曲线
- 工具类：`.page-shell` / `.section-head` / `.product-card` / `.card-soft` / `.chip`
- 全站视觉统一（买/商/管三端）

#### 安全审查与修复（详见 `CODE_REVIEW_REPORT.md`）

- **高危 3 项已修**：商品越权写、子账号权限绕过、发票越权读
- **中危 13 项已修**：支付确认限制、退款金额夹紧、优惠券行锁、状态机死锁、N+1 预取、分页、WebSocket 校验等
- **P0 致命 5 项已修**：支付 Webhook 验签伪造、AI 误下单、购物车加购翻倍、价格类型混入、Webhook 金额/重放防护
- **P1 严重 11 项已修**：结算亏损分摊、退款夹紧、并发超扣、自动退款、登出吊销、CSRF、metrics 鉴权、i18n 性能、直播泄漏等

#### 对标主流电商 UX 改造（17 项全部落地）

| 优先级 | 项 | 说明 |
|---|---|---|
| P0 | 图片画廊、服务承诺条、同类推荐、收藏、全局搜索、购物车地址 | 体验底线 |
| P1 | 五点卖点、吸底购买栏、筛选 chips、空结果兜底、券后价/凑单、评价筛选、截单倒计时、库存紧迫感 | 转化提升 |
| P2 | 自动最优券、图廊悬停放大、预计送达 | 细节加分 |

#### AI 首页个性化（已完成）

- 真实用户画像驱动（非前端假身份选择器）
- LLM 参与楼层决策（顺序+强调楼层）
- 个性化商品召回（推荐/近期/秒杀/热销/评分/店铺）
- 无 AI_API_KEY 时确定性降级，不阻塞主流程

#### 代码质量与测试

- 消除全站 `as any` 类型绕过
- 硬编码角色字符串统一为 `Role` 枚举
- 魔法数字提取为命名常量
- 后端 155 用例全部通过、前端 48 用例全部通过
- `tsc --noEmit` 0 错误
